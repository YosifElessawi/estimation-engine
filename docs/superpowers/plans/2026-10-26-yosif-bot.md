# Yosif's Rule Bot Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A `yosif` bot that bids, Dash Calls and estimates by Yosif's strategy, plays cards with full PIMC, and is rated on the Elo ladder.

**Architecture:**
- A new subpackage, `estimation.bots.yosif`, turns a hand into trick chances:
  - a sampled trump-split model;
  - side-card values by cover and position;
  - "control" (low cards that let you dodge tricks).
- From those chances it gets the probability of taking exactly k tricks for each k, scores each k by SPEC §3, and picks the best legal action.
- Card play is a `PIMCBot` with 30 deals and a new opt-in leader weighting.
- An arena tool reports bidding statistics, and the ladder rates the bot.

**Tech Stack:** Python 3.12, uv, pytest (`-n 2`), pyright, ruff. The existing engine, PIMC and arena code.

**Spec:** `docs/superpowers/specs/2026-10-26-yosif-bot-design.md`. Game rules: `SPEC.md` §2-§3. Engine API: `SPEC.md` §5.

## Global Constraints

- HeuristicBot, PIMC and the RL bots keep their defaults. New behaviour lives in `estimation.bots.yosif`, or behind options that are off by default.
- No randomness in the bot's decisions. The only randomness is PIMC's seeded deal sampling, and the trump model's sampling, which is seeded from its inputs.
- The bot reads only its own `Observation`. The static guard in `tests/bots/test_isolation.py` already scans every file under `src/estimation/bots/` recursively.
- The 120 action ids never change. Every random choice takes an explicit seed.
- Gate: `uv run pre-commit run --all-files`, which runs ruff check, ruff format, pyright and `pytest -q -n 2`.
- Tests use at most 2 workers. Arena and ladder runs use `--workers 5`, one heavy job at a time.
- A Dash Call, bid or estimate decision averages under 10 ms and never exceeds 50 ms.
- Every starting value is a field of a config dataclass, with a comment `[Claude]` or `[Yosif]` saying where it came from.
- Conventional commits ending with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Work on branch `yosif-bot`. No em-dashes in docs, comments or commits.

- [ ] **Step 3: Implement `trumps.py`**

`split_tricks` plays the trump suit out:
- Each round, I lead my highest remaining trump, while any opponent still holds a trump.
- In seat order, each opponent with trumps plays its highest trump if it beats the best card so far, and its lowest otherwise. An opponent with no trumps plays none.
- I win the round if my card is still the best.
- When no opponent has trumps left, every trump I still hold is one more trick.

`trump_odds` estimates the spread by sampling:
- Deal the 39 cards I don't hold at random into three hands of 13, and keep only the trumps of each hand. Draw 400 samples from a `random.Random` seeded with `mine * 4 + long_opponents`.
- With `long_opponents = j`, keep only samples where at least j opponents hold 4 or more of the missing trumps. If no sample can meet that, because too few trumps are missing, ignore the condition.
- Count `split_tricks` on each kept sample and return the shares as a tuple. Memoize with `functools.cache`.

Module docstring: the method is Yosif's ("estimate how many I could collect from this suit by estimating probable deals on other players"), and voids add no separate tricks `[Yosif]`.

### Task 2: Counting a hand

**Files:**
- Create: `src/estimation/bots/yosif/counting.py`
- Test: `tests/bots/yosif/test_counting.py`

**Interfaces:**
- Consumes: `trump_odds` (Task 1).
- Produces:
  - `Chance(win: float, dodge: float)`: frozen dataclass. `win` is the chance the card takes a trick when I want it to; `dodge` is the chance I can avoid that trick when I don't.
  - `Reads(before: int = 0, after: int = 0, bidders: tuple[int, int, int, int] = (0, 0, 0, 0))`: frozen dataclass.
    - `before` and `after` are 4-bit suit masks of the suits bid by the player right before me (`(me + 3) % 4`) and right after me (`(me + 1) % 4`).
    - `bidders[s]` is how many other players bid suit `s` in this auction.
  - `read_bids(obs: Observation) -> Reads`: from `obs.log`, bids only, the bot's own excluded.
  - `HandCount(trumps: tuple[float, ...], side: tuple[Chance, ...])`: frozen dataclass.
  - `CountValues`: frozen dataclass with the defaults below.
  - `count_hand(hand: int, trump: int, reads: Reads = Reads(), over: bool | None = None, values: CountValues = CountValues()) -> HandCount`. `trump` runs 0-3 for the suits and `SANS` (4).

**`CountValues` defaults:** the honours are `[Yosif]`, the numbers `[Claude]` starting values.

| Field | Default | Meaning |
| :--- | :--- | :--- |
| `ace_win` | 1.0 | |
| `ace_dodge` | 0.15 | |
| `ace_dodge_short` | 0.5 | Used when another non-trump suit is void or a singleton, so the ace can be thrown away. |
| `king_alone` | 0.30 | |
| `king_one` | 0.50 | |
| `king_more` | 0.75 | |
| `queen_short` | 0.20 | Alone or with 1 card. |
| `queen_more` | 0.45 | With 2 or more cards. |
| `honour_dodge` | 0.5 | |
| `low_card_dodge` | 0.2 | Added to a K's or Q's dodge per card ranked 2-4 in its suit, capped at 0.95. |
| `position_shift` | 0.25 | |
| `over_factor` | 0.75 | |
| `under_bare_king` | 0.75 | |
| `sans_long_win` | 0.5 | |
| `sans_long_dodge` | 0.5 | |

**Rules:**
- **Trump suit:** `trump_odds(pattern, long_opponents=reads.bidders[trump])`, with the count capped at 3. Trump tricks are never dodged, because every trump either wins or is overtrumped `[Claude]`. Under Sans, `trumps = (1.0,)`.
- **Side suits:**
  - Each A, K and Q adds one `Chance`. In Sans, each card beyond the fourth of a suit headed by an A or K also adds one.
  - **Position:** a K or Q in suit `s` gets `+position_shift` on `win` if `before` has `s`, and `-position_shift` if `after` has `s`, clamped to 0-1.
  - **Over and Under:** with `over=True`, multiply the K and Q `win` by `over_factor`. With `over=False`, a bare K's `win` becomes `under_bare_king`.

### Task 3: Outlook and stakes

**Files:**
- Create: `src/estimation/bots/yosif/odds.py`
- Test: `tests/bots/yosif/test_odds.py`

**Interfaces:**
- Consumes: `HandCount`, `Chance` (Task 2).
- Produces:
  - `spread(chances: Iterable[float]) -> list[float]`: Poisson-binomial distribution.
  - `Outlook(most: tuple[float, ...], least: tuple[float, ...])`: frozen dataclass. `most` is the trick distribution when trying to win, `least` when trying to lose.
  - `outlook(count: HandCount) -> Outlook`: `most` = `trumps` convolved with `spread(win)`; `least` = `trumps` convolved with `spread(win * (1 - dodge))`.
  - `make_chance(o: Outlook, k: int) -> float`: `P(most >= k) - P(least >= k + 1)`, floored at 0. This holds because `least <= most` on the same deal.
  - `expected_miss(o: Outlook, k: int) -> float`: `E[(k - most)+] + E[(least - k)+]`.
  - `Stake(win: float, lose: float, per_trick: float)`: frozen dataclass.
  - `stake(k: int, *, caller: bool, dash: bool, last_risks: int, over: bool | None, rules: RulesConfig) -> Stake`.
    - It covers SCR-1, SCR-2, SCR-3, SCR-4 and SCR-6, with the `RulesConfig` switches respected. SCR-5 and the multipliers are left out.
    - `win` is the points when made. `lose` is the fixed points when missed. `per_trick` is the points lost per trick of miss (SCR-1's `|B - T|`; 0 for Dash and super calls).
    - A Dash stake with `over=None` uses the mean of the Over and Under values.
  - `expected_points(o: Outlook, k: int, s: Stake, others_make: float, rules: RulesConfig) -> float`:
    - `make * (s.win + solo_win) - (1 - make) * (s.lose + solo_lose) - s.per_trick * expected_miss(o, k)`.
    - `solo_win` is 10 × `(1 - others_make) ** 3`; `solo_lose` is 10 × `others_make ** 3`.
    - Both are 0 when `only_winner_loser` is off. Mirror the dash and super switches the same way SCR-5 does.

**`YosifBot(seed: int, config: YosifConfig = YosifConfig())`** has `act(obs, legal) -> int`. Play goes to an inner `PIMCBot(seed, config.pimc)`. Every non-card decision goes to `policy.py`. It raises `RuntimeError` on an illegal choice, like HeuristicBot.

**Decisions** (`policy.py`). Every number choice runs through one helper:

`best_number(o, options, stake_of, others_make, risk: bool, risk_min_make) -> int`
- Normally it maximises `expected_points`.
- With `risk`, it maximises `make_chance × stake.win` among options with `make_chance >= risk_min_make`, and falls back to the normal choice if none qualify.
- Ties go to the lower number.

`needs_jump(obs, jump_points) -> bool`:
- Rounds left = `14 - obs.round_no` in an open round (0 otherwise), plus `len(obs.fixed_left)`.
- True when `max(obs.scores) - obs.scores[obs.seat] > jump_points × rounds left`. Used only if `risk_mode` is on.

The four decisions:

1. **Dash Call** `[Yosif]`:
   - Dash value = `dash_break × P(least == 0)` under the hand's best trump, scored with `stake(dash=True, over=None)`.
   - Compare it with the best non-Dash value: the mean over the five trumps of the best estimate's expected points as a plain estimator, or the best Caller value if that is higher.
   - Dash Call if the Dash value is higher.
2. **Auction** `[Yosif]`: start low, raise on the final turn.
   - For each trump, `target[t]` = `best_number` over k = 4..13, as Caller, with `read_bids(obs)`. Use 4..12 when the bot is the only non-Dash player (AUC-5), so a lone bidder never aims at a bid it can't make.
   - On the final turn (`obs.top_bidder == me`): raise to `bid_action(target[trump], trump)` if it is higher and legal, else Pass.
   - If already With on the top bid: Pass.
   - Otherwise, consider each trump whose lowest beating bid (`heuristic.lowest_bid`) is at most `target[t]`. Bid that lowest bid in the trump with the highest Caller expected points at `target[t]`, but only if that beats the plain-estimator value.
   - Else say With if `WITH` is legal and `target[top trump] >= top tricks`.
   - Else Pass.
3. **Estimate:**
   - Options are the legal estimates. Count with `over` known only for the last estimator, per option: total = estimates so far + k. Add `last_risks = |total - 13| // 2` to the stake.
   - Caller or With stakes apply when k equals the Caller's number, or in the With range.
   - In a fixed-trump round, also consider the legal super calls: `best_number` per other trump over its legal super-call sizes, as Caller. Super-call when that beats the best estimate (design 5.8).
4. **Fixed rounds** use the same code path `[Yosif]`.

**Interfaces:**
- Produces:
  - `RoundRow`: frozen dataclass per finished round, with `fixed`, `skipped`, the Caller's estimate and tricks, and per seat `(estimate, tricks, won, dash, caller, with_, super_)`.
  - `collect(spec: str, games: int, seed: int, workers: int) -> list[RoundRow]`: tables of 4 copies of `spec`, `Bola(seed + i)`, seats seeded `(seed + i) * 4 + seat`.
  - `BidStats`: frozen dataclass with:
    - `open_rounds` and `skipped_share`;
    - `dash_share` and `dash_made`, per player per open round;
    - `with_round_share`;
    - `contract_share` and `contract_made`, as dicts keyed 4..7 and "8+";
    - `super_share`, `super_made`, `fixed_super_calls`;
    - `caller_made` (all contracts).
  - `summarize(rows) -> BidStats` and `format_stats(spec, stats) -> str`.
  - CLI: `python -m estimation.arena.bidstats --bot SPEC --games N [--seed 0] [--workers 1] [--out FILE.json]`.
